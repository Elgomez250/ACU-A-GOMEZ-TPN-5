INICIO SITUACIONES IMÁGENES

Situación 1: ¿Pública o privada?

Consigna: Clasificar las seis direcciones como IP pública o privada.

Respuesta:

192.168.0.15: privada.
10.0.0.5: privada.
200.45.130.12: pública.
172.16.5.20: privada.
8.8.8.8: pública.
192.168.1.1: privada.

Las IP privadas pertenecen a los rangos reservados para redes locales. Las públicas identifican una red ante internet.

Situación 2: Dos casas, la misma dirección

Consigna: Explicar por qué no hay conflicto entre ambos dispositivos.

Respuesta:

No hay conflicto porque 192.168.1.5 es una IP privada. Cada dirección funciona solamente dentro de su propia red local. Los routers utilizan NAT para conectar esas redes con internet mediante sus respectivas IP públicas.

Situación 3: ¿A qué clase pertenece?

Consigna: Indicar a qué clase pertenece cada dirección y su máscara por defecto.

Respuesta:

10.4.5.6: Clase A. Máscara 255.0.0.0.
172.20.14.3: Clase B. Máscara 255.255.0.0.
192.168.50.2: Clase C. Máscara 255.255.255.0.

La clase se identifica observando el primer número de la dirección IP.

Situación 4: El servidor que no puede cambiar de dirección

Consigna: Indicar qué tipo de IP conviene para el servidor y para las notebooks, y nombrar el protocolo de asignación automática.

Respuesta:

Al servidor le conviene una IP estática porque necesita mantener siempre la misma dirección. A las notebooks les conviene una IP dinámica, que se asigna automáticamente mediante el protocolo DHCP.

Situación 5: Se están por acabar las direcciones

Consigna: Explicar cómo pueden seguir conectándose dispositivos usando IP pública, privada y NAT.

Respuesta:

Los dispositivos utilizan IP privadas dentro de las redes locales. El router, mediante NAT, permite que muchos dispositivos compartan una sola IP pública para conectarse a internet. De esta manera, se aprovechan mejor las direcciones IPv4 disponibles.

Situación 6: La casa que se pasa a IPv6

Consigna: Explicar las diferencias entre IPv4 e IPv6 y por qué IPv6 resuelve el problema de agotamiento.

Respuesta:

IPv4 utiliza 32 bits y se escribe con cuatro números separados por puntos. IPv6 utiliza 128 bits y se escribe con números y letras separados por dos puntos. IPv6 permite una cantidad muchísimo mayor de direcciones, por eso soluciona el problema de agotamiento de IPv4.

Situación 7: Probar la red sin estar conectado

Consigna: Indicar qué dirección especial puede utilizar, a qué dispositivo hace referencia y por qué no necesita conexión.

Respuesta:

Puede utilizar la dirección 127.0.0.1, llamada Loopback. Esta dirección hace referencia a la propia computadora y permite comprobar si funciona correctamente el software de red sin conectarse a internet ni a una red física.

Situación 8: Todo bien adentro, nada afuera

Consigna: Explicar para qué sirve la puerta de enlace y qué dispositivo debe tener configurada su dirección.

Respuesta:

La puerta de enlace es la dirección IP del router y funciona como salida hacia otras redes o internet. Si está mal configurada, la computadora puede comunicarse con los dispositivos de su red local, pero no puede acceder a internet. Por eso debe tener configurada correctamente la dirección del router.

Situación 9: Misma red, redes distintas

Consigna: Explicar por qué A y B pueden comunicarse directamente, mientras que para comunicarse con C necesitan un router.

Respuesta:

Las PC A y B pertenecen a la misma red porque sus direcciones comparten la parte de red 192.168.1 y tienen la misma máscara. En cambio, la PC C pertenece a otra red porque su parte de red es 192.168.2. Por eso necesitan un router para comunicarse.

Situación 10: Diagnóstico integral de la oficina

Consigna: Explicar qué tipo de IP tiene el servidor, qué IP recibe la notebook, qué función cumple el router y por qué necesita una IP pública.

Respuesta:

El servidor tiene una IP estática porque necesita mantener siempre la misma dirección. La notebook recibe una IP dinámica mediante el protocolo DHCP. La dirección 192.168.1.1 es la IP privada del router y funciona como puerta de enlace. Además, el router necesita una IP pública asignada por el proveedor de internet para conectar la red local con internet mediante NAT.
